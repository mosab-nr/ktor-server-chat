# Ktor Server For Chat

A simple chat server built with [Ktor](https://ktor.io/) and Kotlin.

## Overview

This project provides the backend for a chat application. It is designed to handle real-time communication and server-side chat logic using Ktor.

## Features

- Kotlin-based backend
- Built with Ktor
- Lightweight and scalable server architecture
- Suitable foundation for chat and messaging APIs

## Getting Started

### Prerequisites

- JDK 17 or newer
- Gradle

### Run the project

```bash
./gradlew run
```

## Project Structure

The codebase is organized as a Ktor server application and can be extended with routes, services, and persistence layers as needed.
